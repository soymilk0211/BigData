AI Agent 建立策略
透過既有的 skill 範本，

先由 使用者 撰寫 需求描述，接著交由 AI 自動化完成整個 skill 的建置流程。

優勢：AI 依據需求生成對應的 skills 檔案，也能產出相關程式碼。

技巧：需求描述要盡量明確，每一個 Agent 負責一個功能。

scripts/   自動化腳本

           l 讓 AI 直接執行的程式碼，通常是 Python 或 Shell 腳本。
           l 不需要自己會寫程式。 由 AI 幫你寫腳本，放在這個資
             料夾裡。之後執行 Skill 時，能直接呼叫這些腳本。

           l 什麼時候需要腳本？
              當任務涉及跟外部系統互動時
              l 呼叫 PubMed API 搜尋文獻
              l 讀取 CSV / Excel 檔案並做計算
              l 呼叫化學資料庫（如 PubChem）查詢分子資訊
              l 把數據轉換成特定格式

           l 什麼時候不需要？
              指導 AI 如何思考和回答
              l 教 AI 用你的 SOP 格式撰寫實驗報告
              l 教 AI 按照特定邏輯分析文獻
              l 教 AI 用你實驗室的命名規範來整理資料

assets/   輸出模板

          最終產出物的「骨架」。當你希望 AI 產出的報告、文件有固
          定的格式和結構時，把模板放在這裡。

          類比： 你的 lab notebook 模板、期刊投稿的 Word 模板、規
          定的報告格式。

          範例：
          irb-application-template.md：IRB 倫理審查申請書的格式範本
          case-report-template.md — 個案報告模板（含 CARE 清單欄位）
          safety-assessment-template.md — 化學品安全評估報告模板
          analytical-report-template.md — 分析報告模板（含 QC 數據格
          式）

讓AI根據模板建立 AI Agents 範例 (3/3)
請根據提供的 skill 模板（skill-template.zip），建立一個用於 PubMed 文獻蒐集的 AI Agents 系統。

系統需包含三個 Agent，並具備以下功能與流程：

Agent 1：需求釐清與搜尋策略生成
負責與使用者進行對話，逐步蒐集並釐清文獻搜尋需求，包括研究領域、關鍵字與文獻類型（例如：方法學研究、最新研究發現、Review 等）。
最終需整理並輸出：

關鍵字（Keywords）

文獻需求描述（Research Intent）

可用於 PubMed 或 Google Scholar 的搜尋語句（Search Queries）

Agent 2：文獻抓取與初步分類
根據 Agent 1 產生的搜尋語句，從 PubMed 擷取約 30 篇文獻（或提供使用者自訂數量的選項）。
針對每篇文獻的標題與摘要進行分析，並完成初步分類（例如：研究類型、主題分類等）。

Agent 3：摘要整理與輸出
依據使用者選擇的分類結果，彙整並輸出對應文獻的摘要內容，提供結構化整理，協助使用者快速掌握重點。

其他要求

請依照 skill 模板自動生成所有必要的 skills 檔案與相關程式碼

系統架構需清楚區分三個 Agents 的責任與資料流

輸出內容應具備良好的可讀性與可擴展性

步驟一：打開 SKILL.md 檔案，觀察是否有完整涵蓋規格，如果不完備，可直接
修改SKILL.md檔案的內容。



步驟二：輸入三～五個問題，觀察SKILL 是否有被啟動；如果不滿意，重新修

更格式化。

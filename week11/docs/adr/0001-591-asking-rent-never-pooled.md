# 591 刊登租金與實價登錄租金永不合併

本 Skill 以目標地區為範圍爬取 591 租屋網的刊登資料（參考 Rent591Watcher 的取得方式，該專案無授權條款，只註明出處、不複製程式碼），用來補足物件細節與踩雷訊號，並另外統計刊登租金。刊登租金是開價、實價登錄租金是已申報的租賃案件，兩者偏誤方向不同，因此兩者只並列比較（例：刊登比實價登錄高幾 %），永遠不合併成同一個行情分組；價格過低／過高（R1、R2）只依實價登錄判斷。

## 考慮過的選項

- 只接受使用者貼上的刊登內容：最保守，但無法提供區域層級的刊登行情，也無法自動取得物件細節，因此不採用。
- 將兩種租金合併以擴大樣本：樣本變多，但會把開價偏誤混進行情，讓「貴不貴」的判斷失真，因此不採用。

## 後果

- 591 資料只保存去識別化欄位，不存姓名、電話、LINE、門牌與原始網頁；測試使用提交在 sample-data 的去識別化快照，不依賴即時連線。
- reviewer 增加一項檢核：實價登錄行情統計中不得出現刊登來源的資料。

# 課程講義：student-rental-check——台灣學生租屋行情與避雷 Claude Skill

> 本講義搭配影片（https://youtu.be/pKZa5sm2O5o ，總長 5:43，精確 5:43.67，edge-tts Yunjian 旁白＋燒錄字幕；公開 repo 不保留 mp4）與字幕 `subtitles.zh-TW.srt`（95 段）使用。括號中的時間是影片時間點，章節表見 `chapters.md`。所有數字都來自 `test-logs/` 的實際執行紀錄。

## 1. 這個 Skill 做什麼（0:00–0:32）

- **名稱**：student-rental-check（台灣學生租屋行情與避雷檢查）。
- **要解決的問題**（0:05–0:11）：學生找房常遇到三件事——不知道租金合不合理、看不到管理費與水電等隱藏成本、訂金詐騙。
- **資料來源**（0:12–0:25）：
  - 內政部**實價登錄**「不動產租賃」開放資料：每季一個壓縮檔，全國 21 個縣市各一個檔案。
  - 實價登錄的**備註欄**常寫管理費，collector 會解析出來。
  - **591 房屋交易網**的刊登資料只當補充對照：刊登價≠成交價，兩者並列、永不合併。
- **預期成果**（0:26–0:31）：一份 `final_report.md`，包含行情位置、**真實每月總成本**（已知項目合計＋未提供項目）和踩雷提醒。

## 2. Skill 架構（0:32–1:11）

- 資料夾依老師範本命名為 `team-XX-skill/`，內含 `SKILL.md`、`agents/`、`scripts/`、`references/`、`sample-data/`。
- **Trigger（觸發條件）**＝ `SKILL.md` 開頭 frontmatter 的 `name` 與 `description`（0:33–0:46）：
  - 應啟動：學校附近找房、租金貴不貴。
  - 不要用於：買房、國外租屋、一般程式問題。
- 角色之間用 **handoff JSON** 交接，寫明輸入、輸出與下一棒（1:05–1:10）。

### 五個 Agent（0:47–1:04）

| # | Agent | 只負責 | 何時啟用 |
| --- | --- | --- | --- |
| ① | **collector** 蒐集員 | 解析地區（縣市＋區、學校查表、地址），取得實價登錄與 591 資料，整理候選物件 | 一律 |
| ② | **fact-checker** 時效驗證員 | 標記過時、重複、來源不明、未提供的資料；**只標記、不刪資料** | 一律 |
| ③ | **quant-analyst** CP 值精算師 | 行情統計（中位數、四分位數）、真實每月總成本、排序、刊登租金對照、判定高風險訊號 R1–R7 | 一律 |
| ④ | **devil-advocate** 踩雷獵人 | 挑戰排名第一的物件，寫踩雷報告 | **條件啟動**：只有 R1–R7 有訊號時 |
| ⑤ | **reviewer** 審查員 | 用獨立腳本從原始資料重算抽查，組成最終報告 | 一律 |

流程：使用者需求 → Trigger → collector → fact-checker → quant-analyst →（有訊號才）devil-advocate → reviewer → `final_report.md`。

**devil-advocate 什麼時候啟動？** quant-analyst 寫出高風險訊號；有訊號（例如 R3「先匯訂金才能看房」）就啟用 devil-advocate；沒有訊號就略過，並在 `00_routing.json` 記錄，而且**不讀** `agents/devil-advocate.md`（測試 A 就是這樣，1:40–1:44；測試 B 則有啟動，3:35–3:55）。

## 3. 怎麼證明 Skill 有自動啟動：證據等級 E0–E3（1:11–1:56）

測試都用 Claude Code 非互動模式 `claude -p` 執行，提示詞**沒有指名 Skill、沒有斜線指令**（自動觸發）。不是只看回答，而是看 stream-json 的工具呼叫紀錄（1:18–1:23）：

| 等級 | 證據 | 意義 |
| --- | --- | --- |
| E0 可用 | `system/init` 事件的 `skills` 含 `student-rental-check` | 只證明已安裝，不算啟動；反向測試用它證明「沒啟動不是因為沒裝」 |
| E1 自動選用 | `tool_use` 名稱是 Skill、參數是 `student-rental-check` | **主要證據**（影片中即時執行的第一個工具呼叫，1:24–1:27） |
| E2 依分工執行 | 之後用 Read 讀角色檔、執行腳本 | 照 SKILL.md 的角色與路由執行 |
| E3 可核對輸出 | 輸出檔、`validate.py` 結束碼 0、審查紀錄 | 產出符合規格 |

## 4. 測試結果

### 測試 A：應啟動（1:11–1:56）

- 提示詞：長庚大學新生，龜山區獨立套房，月租 9,500 元、權狀 8 坪、管理費 800 元、電費每度 5 元等。
- **即時執行**（1:11–1:33）：影片中用 `claude -p` 即時跑測試 A，提示詞沒有指名 Skill；第一個工具呼叫就是 Skill（E1），接著用 Read 讀入 `collector.md`（1:28–1:32）。畫面加速約 1.3 倍，右下角有倍速標示。
- **完整 log 證據**（1:33–1:56）：先呼叫 Skill（E1）→ 再用 Read 讀四個角色檔（E2，1:37–1:39）→ 沒有高風險訊號，`00_routing.json` 記錄略過 devil-advocate（1:40–1:44）。
- 數字：**真實每月總成本：已知項目合計 12,618 元**；未提供：水費、瓦斯、網路，另外列出，不當成 0 元（1:45–1:55）。
- **V-A 這次完整執行的審查結果是 FAIL**（4:55–5:05）：reviewer 的 V8（報告數字可追溯）把報告數字 4446、3588 判為在舊排除規則下無法追溯。已修正（見第 5 節）。

### 測試 B：換說法、換城市，仍應啟動（1:56–4:27）

- 提示詞：在**逢甲**附近找房，兩間比較：第一間分租套房 7 坪、月租 7,000，房東要**先匯訂金才能看房**；第二間雅房 5,500，管理費不知道。
- **即時執行**（1:56–2:12）：第一個 tool_use 一樣是 Skill student-rental-check（2:02–2:05）。`resolve_area` 用學校對照表把「逢甲」對到**臺中市西屯區**（2:07–2:11）。
- **互動畫面重播完整流程**（2:12–4:27）：系統自動喚起 Skill（2:18–2:21）；五個角色就位，踩雷獵人只在高風險時出場（2:22–2:26）。
  - collector（2:27–2:49）：全市 30,596 筆，西屯留下 4,782 筆；591 刊登快照 3,881 筆；候選套房 7 坪 7,000 元，雅房 5,500 元沒寫坪數。
  - fact-checker（2:51–3:06）：標記 4,062 筆，刪除 0 筆；約 55% 是社宅；兩間缺來源、日期、雜費，第二間缺坪數。
  - quant-analyst（3:07–3:34）：套房中位數 8,000 元，排除社宅 10,500 元，雅房 6,400 元；第一間每坪 1,000 元，價格合理；R3 先匯訂金，R6 來源日期不明。
  - devil-advocate（3:35–3:55）：R3 觸發；第一間高風險，可能是假房東或二房東，沒看房別匯錢；第二間命中 R6 也高風險；排名第一不等於可以租。
  - reviewer（3:56–4:09）：獨立重算 PASS，重試 0 次；591 刊登價沒混進官方行情。
  - 最終報告（4:11–4:26）：第一間先別碰，第二間可以繼續問；還不能確定第二間比較划算；缺的雜費可能讓名次反轉。
- **不限長庚**：測試 B 在台中，證明 Skill 不限長庚附近，全台各縣市都能用（2:07–2:11）。

### 測試 C：不應啟動（4:27–4:41）

- 影片中**即時執行**：問一個一般的 Python 反轉字串問題（4:28–4:33）。
- 證據：Skill 呼叫次數是 0；description 寫明一般程式問題不啟動，所以沒有誤啟動（4:33–4:40）。

## 5. 除錯紀錄（4:41–5:12）

- **description 從 v1 到 v2 一字未改**（4:42–4:46）。
- 開發試跑時，模型用 `cat` 讀角色檔，log 沒有 Read 證據（4:47–4:51）→ 修正後規定一律用 Read 工具（4:52–4:54）。
- **測試 A 完整執行時 reviewer 判 V8 FAIL**（4:55–5:05）：報告數字 4446、3588 在舊排除規則下無法追溯。
- **修正規則後再跑回歸測試 A-5，判 PASS，validate.py 也通過**（5:06–5:11）。

## 6. 成果總結與限制（5:12–5:31）

- **總結**（5:13–5:21）：測試 A 與 B 正確啟動、測試 C 沒有誤啟動；五個角色完整交接並由 reviewer 判 PASS。
- **限制**（5:22–5:30）：實價登錄只含已申報案件，學校對照表有限；電費上限未查證，R5 暫不判定。

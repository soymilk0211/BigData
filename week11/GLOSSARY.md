# 學生租屋行情與避雷（student-rental-check）

學生在台灣各縣市找房時，判斷候選物件價格是否合理、真實花費多少、有沒有踩雷風險的領域用語。

## 租金與價格

**實價登錄租金**：
內政部實價登錄租賃資料中，已申報的租賃案件月租（總額元）。是行情統計唯一的依據。
_避免_：成交價、行情價、市價

**刊登租金**：
租屋平台（例如 591）或房東刊登時開出的月租，尚未成交。只能單獨列為參考，不得與實價登錄租金合併計算。
_避免_：開價、591 價、行情

**每坪租金**：
扣除車位租金與車位面積後，月租除以登記坪數（含公設）。
_避免_：坪價、單價（官方「單價元平方公尺」是另一個以平方公尺計的欄位）

**真實每月總成本**：
候選物件每月實際要付出的金額：租金加上另計的管理費、水電瓦斯網路等隱藏成本，以及通勤時間成本與交通費。
_避免_：總租金、實付租金

**隱藏成本**：
月租以外、入住後每月必須另外支付的費用，例如管理費、電費、水費、瓦斯、網路。
_避免_：雜費、額外費用

## 物件與地區

**候選物件**：
使用者正在考慮、要被評估或比較的一間房，可來自使用者描述、使用者貼上的刊登內容或模擬資料。
_避免_：物件、房源、listing

**目標地區**：
本次分析所用的「縣市＋鄉鎮市區」，只能由使用者指定、學校查表、地址解析或使用者確認得出，不可猜測。
_避免_：區域、附近、商圈

**行情分組**：
用來比對候選物件的一群實價登錄案件，以目標地區、出租型態分組與分析期間界定。
_避免_：樣本、母體、市場

## 風險

**高風險訊號**：
R1–R7 任一條件成立，代表需要啟用踩雷獵人進一步檢查。
_避免_：警訊、紅旗、危險物件

## 測試

**啟動**：
Claude Code 的執行紀錄中出現 `Skill` 工具呼叫，且呼叫的是本 Skill；只讀到 Skill 清單不算啟動。
_避免_：觸發成功（未附 log 證據時）、有用到

**手動觸發**：
使用者以斜線指令或明確指名要求使用本 Skill，不計入自動啟動次數。
_避免_：強制啟動
